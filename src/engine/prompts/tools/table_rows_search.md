<table_rows_search>

### Назначение
Получить строки табличного документа по диапазону индексов.

### Особенности использования
- Лимит — 50 строк за вызов.
- Общее количество строк отображается в каждом вызове.
- Для получения большего количества вызывай несколько раз со смещением `row_from`/`row_to`.

### Зависимости
`file_id` — UUID документа с `is_table=true`, получи через `list_own_documents` или `list_documents`.

### Пример использования
**Плохой запрос**:
    file_id: "8d0c0ad4-4746-4707-8636-518e4fd2bbea"
    row_end: 1100
    row_start: 0
**Хороший запрос**:
    Вызов №1:
    file_id: "8d0c0ad4-4746-4707-8636-518e4fd2bbea"
    row_end: 50
    row_start: 0
    Вызов №2:
    file_id: "8d0c0ad4-4746-4707-8636-518e4fd2bbea"
    row_end: 100
    row_start: 51
    ...
**Почему**: соблюдай лимиты при вызовах, разбивай большие вызовы на меньшие. Потому что инструмент не берёт более 50 строк за 1 вызов в любом случае.
