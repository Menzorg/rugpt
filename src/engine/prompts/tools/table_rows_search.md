# table_rows_search

Получить строки табличного документа по диапазону индексов. Лимит — 50 строк за вызов. Общее количество строк можно посмотреть в любом вызове; для большего количества вызывай несколько раз со смещением `row_from`/`row_to`.

**Зависимости:** `file_id` — UUID документа с `is_table=true`, получи через `list_documents`.
