### Назначение
Найти собственные документы пользователя.

### Особенности использования
- `name_query` — поиск по ключевым словам в имени файла и его кратком содержании.
- `summary_query` — поиск по абстрактному описанию краткого содержания файла.
- `page` — номер страницы (по умолчанию 1, по 50 документов на каждой странице, сортировка по дате создания).
- В прямом чате возвращает приватные и публичные документы пользователя. Когда агент вызван через упоминание — только публичные документы вызванного пользователя.
- Нельзя отвечать на вопросы по содержимому документов без последующего применения `rag_search`.
- Документы без статуса "indexed" недоступны для поиска по содержимому.
- Не игнорируй непросмотренные страницы при поиске, либо говори какие из имеющихся страниц просмотрел, а какие нет.

### Ограничения
Не более 8 вызовов за сессию.
