# task_update

Изменить статус, заголовок, описание, срок или участников существующей задачи. Хотя бы один параметр должен быть заполнен.

## Переходы статусов

| Текущий статус | Кто может менять | Допустимые новые статусы |
|---|---|---|
| `created` | Исполнитель | `in_progress` |
| `in_progress` | Исполнитель | `awaiting_review` |
| `awaiting_review` | Создатель | `in_progress` (вернуть на доработку), `done` (принять) |
| `done` | — | Нельзя изменить |

Статус `overdue` устанавливается автоматически — передавать его запрещено, инструмент вернёт ошибку.

## Срок (`deadline`)

- **Создатель / администратор** — устанавливает срок напрямую, вступает в силу немедленно.
- **Исполнитель** — отправляет предложение по сроку; создатель должен его принять через `task_deadline_proposal`. Инструмент вернёт подтверждение отправки предложения.
- Все остальные — изменение срока запрещено.
- Статус `overdue` — изменение срока запрещено для всех.

Формат: ISO, например `2025-03-15T18:00:00`.

## Поля и права

`title`, `description`, `new_participant_user_ids`, `delete_participant_user_ids` — только создатель или администратор.

**Зависимости:** `task_id` — UUID задачи, получи через `task_query`. UUID участников — через `user_search`.
