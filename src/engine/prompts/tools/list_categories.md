### Назначение
Найти категории документов (типы контента), настроенные администратором для организации.

### Особенности использования
- `query` — нечёткий поиск по имени категории с поддержкой опечаток и частичных совпадений;
- без `query` (или с пустой строкой) возвращает все активные категории организации;
- результат содержит `id`, `name` и `description` каждой категории;
- рекоммендуется искать сначала с `query`, а если категория не найдена, то без `query` просмотреть весь список категорий.

### Зависимости
Возвращённый `id` передаётся в параметр `category_id` инструмента `list_documents`, чтобы ограничить поиск документами нужной категории.
