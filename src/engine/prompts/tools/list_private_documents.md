# list_private_documents
Инструмент для поиска только собственных документов пользователя — чужие файлы не включаются. Использовать, когда пользователь спрашивает именно о своих файлах.

`name_query` — поиск по ключевым словам в имени файла и его кратком содержании
`summary_query` — поиск по абстрактному описанию краткого содержания файла
`page` — номер страницы при перечислении (по умолчанию 1, по 50 документов, сортировка по дате создания)

## Правила использования
Нельзя получить никакой информации по документам, которые не имеют статус "indexed".
Выдавать пользователю ответы на вопросы по содержимому документов исключительно этим инструментом без последующего применения `rag_search` запрещено.

**Зависимости:** Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.

**Ограничения:** Не более 10 вызовов за сессию
