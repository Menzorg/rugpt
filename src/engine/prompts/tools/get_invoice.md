<get_invoice>

### Назначение
Получить детальную информацию об одном счёте по его id.

### Особенности использования
- `invoice_id` — UUID счёта; получи из вывода `list_invoices`.
- Администратор может читать любой счёт организации. Не-администратор — только счета, загруженные им самим.
- Возвращает ошибку, если id недействителен или счёт недоступен вызывающему.

### Вывод
Имя файла, `file_id`, статус, срок оплаты, загрузчик, ориентировочная сводка файла, причина отклонения (если статус `rejected`). Для табличных счетов добавляется флаг `is_table: true`.

### Примечания
- Для табличных счетов (`is_table: true`) используй `table_rows_search` по `file_id`; для текстовых документов — `rag_search` по `file_id`.
- Для счетов-изображений инструмент может дополнительно вернуть само изображение для прямого анализа (включается отдельным экспериментальным флагом).

</get_invoice>
