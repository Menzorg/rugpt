### Назначение
Найти фрагменты текста внутри конкретного табличного или нетабличного документа (`is_table`=false).

### Особенности использования
- Поиск ведётся только в пределах одного документа — для поиска по нескольким вызывай инструмент отдельно для каждого.
- `rag_search` лучше работает только с атомарными запросами. 1 тема или наименование на 1 использование. Не объединяй в одном `query` разные признаки через длинный список. Делай отдельные вызовы:
   - точная формулировка из вопроса пользователя;
   - ключевое существительное/термин без лишнего контекста;
   - синоним, сокращение, код, номер, дата или альтернативное написание;
   - более широкий термин, если точные запросы дали мало.

### Зависимости
`file_id` — UUID документа, получи через `list_own_documents`, `list_documents` или из приложенных файлов в чате.
