# rag_search

Найти релевантные фрагменты текста внутри конкретного нетабличного документа (`is_table`=false). Поиск ведётся только в пределах одного документа — для поиска по нескольким вызывай инструмент отдельно для каждого.

**Зависимости:** `file_id` — UUID документа, можно получить через `list_documents`. Часть результата (`chunk_index`) - необходима для `expand_chunk`.
