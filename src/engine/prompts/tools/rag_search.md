# rag_search

Найти фрагменты текста внутри конкретного нетабличного документа (`is_table`=false). Поиск ведётся только в пределах одного документа — для поиска по нескольким вызывай инструмент отдельно для каждого.
Рекомендованый формат запросов: websearch, конкретика, ключевые слова.

**Зависимости:** `file_id` — UUID документа, можно получить через `list_documents` или из приложенных файлов в чате. Часть результата (`chunk_index`) - необходима для `expand_chunk`.

**Особенности:** Большое количество запросов обязательно нужно разбивать на пачки по 10.
