### Назначение
Найти фрагменты текста внутри конкретного табличного или нетабличного документа (`is_table`=false).

### Особенности использования
- Поиск ведётся только в пределах одного документа — для поиска по нескольким вызывай инструмент отдельно для каждого.
- Рекомендуемые форматы запросов: 
    1. websearch, конкретика, ключевые слова (если поиск по конкретным формулировкам, известным заранее названиям разделов, терминам)
    2. абстрактное описание нужного чанка (если для поиска не дано конкретной информации)

### Зависимости
`file_id` — UUID документа, получи через `list_own_documents`, `list_documents` или из приложенных файлов в чате.
