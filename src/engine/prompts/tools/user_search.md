<user_search>

### Назначение
Найти сотрудников организации. Используй перед любым инструментом, которому нужен `user_id`.

### Особенности использования
- `name_query` — подстрока в имени или логине.
- `role_code` — фильтр по коду роли (`lawyer`, `accountant`, `pm` и т.д.).

### Ограничения
- Возвращает только пользователей, видимых вызывающему (видимость по отделам).
- Системные (AI) пользователи исключены.
- Лимит — 50 результатов за 1 вызов.
