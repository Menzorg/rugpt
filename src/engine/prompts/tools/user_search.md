# user_search

Найти сотрудников организации. Используй перед любым инструментом, которому нужен `user_id`. Возвращает только пользователей, видимых вызывающему (видимость по отделам); системные (AI) пользователи исключены. Лимит — 50 результатов. Фильтры: `name_query` — подстрока в имени или логине, `role_code` — код роли (`lawyer`, `accountant`, `pm` и т.д.).
