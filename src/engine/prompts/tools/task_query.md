# task_query

Найти задачи по одному или нескольким фильтрам. Все активные фильтры пересекаются. Без фильтров — все задачи организации. Задачи исполнителей, невидимых вызывающему, исключаются.

Результат разбит на страницы по 50 задач. Используй `page` для навигации; в заголовке ответа указан диапазон и общее количество (`1–50 of 143, page 1/3`).

Если суммарный объём описаний превышает бюджет, описания скрываются — сузи выборку фильтрами.

Если у задачи есть ожидающее предложение по сроку, оно отображается в поле `proposed_deadline` рядом с именем предложившего. Для принятия или отклонения используй `task_deadline_proposal`.

Фильтры по датам: `deadline_from`/`deadline_to` — по сроку, `created_from`/`created_to` — по дате создания.

**Зависимости:** `assignee_user_id` и `created_by_user_id` — UUID пользователей, получи через `user_search`.
