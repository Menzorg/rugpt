# task_query

Найти задачи по одному или нескольким фильтрам. Все активные фильтры пересекаются. Без фильтров — все задачи организации (лимит 200). Задачи исполнителей, невидимых вызывающему, исключаются. Если суммарный объём описаний превышает бюджет (20 000 символов), описания скрываются с предупреждением — сузь выборку фильтрами. 
Фильтры по датам: `deadline_from`/`deadline_to` — по сроку, `created_from`/`created_to` — по дате создания.

**Зависимости:** `assignee_user_id` и `created_by_user_id` — UUID пользователей, получи через `user_search`.
