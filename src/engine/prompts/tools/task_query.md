<task_query>

### Назначение
Найти задачи по одному или нескольким фильтрам.

### Особенности использования
- Все активные фильтры пересекаются. Без фильтров — все задачи организации.
- Результат разбит на страницы по 50 задач; используй `page` для навигации (заголовок ответа содержит диапазон и общее количество).
- Фильтры по датам: `deadline_from`/`deadline_to` — по сроку, `created_from`/`created_to` — по дате создания.
- Если у задачи есть ожидающее предложение по сроку, оно отображается в поле `proposed_deadline`. Для принятия/отклонения используй `task_deadline_proposal`.
- Если суммарный объём описаний превышает бюджет, описания скрываются — сузи выборку фильтрами.

### Ограничения
Задачи исполнителей, невидимых вызывающему, исключаются.

### Зависимости
`assignee_user_id` и `created_by_user_id` — UUID пользователей, получи через `user_search`.
