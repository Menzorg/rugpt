# task_create

Создать задачу и назначить её сотруднику. `created_by_user_id` проставляется автоматически из контекста.
`priority` - 1=Обычно, 2=Важно, 3=Срочно. Значение по умолчанию зависит от назначившего (руководитель=3, глава отдела=2, работник=1).

**Зависимости:** `assignee_user_id` — UUID исполнителя, получи через `user_search` если неизвестен. Исполнитель должен быть виден вызывающему (видимость по отделам), иначе вернётся ошибка.

`participant_user_ids` — необязательный список UUID дополнительных участников задачи. Если пользователь называет участников по именам, сначала получи их UUID через `user_search`; участники тоже должны быть видимы вызывающему.
