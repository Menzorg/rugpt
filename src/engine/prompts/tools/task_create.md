# task_create

Создать задачу и назначить её сотруднику. `created_by_user_id` проставляется автоматически из контекста.

**Зависимости:** `assignee_user_id` — UUID исполнителя, получи через `user_search` если неизвестен. Исполнитель должен быть виден вызывающему (видимость по отделам), иначе вернётся ошибка.
