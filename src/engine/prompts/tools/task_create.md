# task_create

Создать задачу и назначить её сотруднику. `created_by_user_id` проставляется автоматически из контекста.

`priority` — 1=Обычно, 2=Важно, 3=Срочно. **Всегда уточняй приоритет у пользователя перед созданием — не угадывай.**
`deadline` — срок в ISO-формате, например `2025-03-15T18:00:00`.
`participant_user_ids` — необязательный список UUID дополнительных участников задачи.

**Зависимости:** `assignee_user_id` и элементы `participant_user_ids` — UUID пользователей, получи через `user_search` если неизвестны. Исполнитель и участники должны быть видимы вызывающему (видимость по отделам), иначе вернётся ошибка.
