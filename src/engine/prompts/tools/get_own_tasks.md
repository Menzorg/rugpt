### Назначение
Получить задачи, назначенные владельцу роли.

### Поведение
- При вызове через упоминание (`@@role`) возвращает задачи **упомянутого пользователя** (callee).
- При прямом обращении к роли возвращает задачи **вызывающего пользователя** (caller).

### Фильтрация по умолчанию (без `status`)
Скрываются:
- задачи со статусом `done`
- задачи со статусом `overdue`, у которых дедлайн истёк более 30 дней назад

Чтобы увидеть их, передай явный `status`.

### Параметры
- `status` — опциональный фильтр: `created`, `in_progress`, `done`. Без значения — активные задачи с отсечением по правилам выше.
- `page` — номер страницы (по 50 задач, по умолчанию 1).

### Формат ответа
Заголовок с диапазоном и числом страниц, затем список задач с полями: статус, название, срок, id, создатель, участники, описание.
