<call_helper>

### Назначение
Вызвать внутреннего вспомогательного агента (хелпера) для выполнения подзадачи и вернуть его ответ.

### Особенности использования
- Запрос (`query`) должен быть самодостаточным — хелпер не видит историю диалога и не знает контекста.
- Включай в `query` максимум контекста, который может потребоваться выбранному хелперу.
- Формулируй `query` предельно конкретно, не опуская ни единой подробности, указанной пользователем.

**Доступные хелперы:**

`doc_search_helper` — ищет информацию в документах организации: листает доступные файлы, ищет релевантные фрагменты, при необходимости расширяет контекст найденных чанков. Использовать когда пользователь спрашивает о содержимом загруженных документов или нужно собрать данные из базы знаний. 
В `query` указывай: вопрос, UUID файла если известен из приложений диалога, область поиска (свои документы или вся база знаний).
