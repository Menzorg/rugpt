# task_deadline_proposal

Принять или отклонить предложение исполнителя по новому сроку задачи. Только создатель задачи может вызывать этот инструмент.

`task_id` — UUID задачи с ожидающим предложением (узнай через `task_query`, поле `proposed_deadline`).
`accept` — `true` чтобы принять предложение (срок вступает в силу немедленно), `false` чтобы отклонить.

Если у задачи нет ожидающего предложения, инструмент вернёт ошибку.
