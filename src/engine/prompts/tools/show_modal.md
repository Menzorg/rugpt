<show_modal>

### Назначение
Показать пользователю модальное окно с кнопками действий. Инструмент не изменяет данные — только отображает карточку. При нажатии кнопки на бэкенде выполняется обработчик выбранного `action_type`.

### Особенности использования
- `title` — заголовок модального окна.
- `body` — тело модального окна (поддерживает markdown).
- `actions` — список кнопок (одна или несколько). Каждая кнопка содержит:
  - `label` — текст кнопки, видимый пользователю.
  - `action_type` — зарегистрированное действие на бэкенде, которое сработает при нажатии.
  - `params` — параметры для обработчика действия (должны соответствовать его схеме).
- `target` (необязательно) — подсказка фронтенду о ресурсе, к которому относится модал, например `{"type": "invoice", "id": "<uuid>"}`.

### Зависимости
Только `action_type` из списка `agent_config.allowed_action_types` роли допустимы. При попытке использовать незарегистрированный или запрещённый `action_type` вернётся строка с ошибкой — не повторяй вызов с тем же значением.

Возвращает `"Modal shown."` при успехе.

</show_modal>
