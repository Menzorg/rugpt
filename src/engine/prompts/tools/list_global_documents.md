# list_global_documents
Инструмент для поиска публичных документов организации. Использовать, если пользователь ищет файлы по организации, а не только свои.

`name_query` — поиск по ключевым словам в имени файла и его кратком содержании
`summary_query` — поиск по абстрактному описанию краткого содержания файла
`owner_id` — фильтр по UUID автора: перечислить все документы конкретного пользователя

## Правила использования
**Обязателен хотя бы один из фильтров:** `name_query`, `summary_query` или `owner_id`. Вызов без фильтров вернёт ошибку.
Без текстовых фильтров (`name_query` / `summary_query`) перечисление документов доступно только через `owner_id`.

Нельзя получить никакой информации по документам, которые не имеют статус "indexed".
Выдавать пользователю ответы на вопросы по содержимому документов исключительно этим инструментом без последующего применения `rag_search` запрещено.

**Зависимости:** Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.

**Ограничения:** Не более 5 вызовов за сессию
