# list_documents

Показать документы, доступные вызывающему в его организации. Без фильтров: если документов ≤ 75 — полный формат с размером и кратким содержанием; если > 100 — компактный список (id, имя файла, `is_table`), усечённый до 500. Чтобы найти нужный документ в большом каталоге — используй `name_query` или `summary_query` (оба идут через векторный поиск).
Инструмент не ищет изображения в базе документов.
При фильтрованном поиске, инструмент возвращает полную информацию о документе.

## Правила использования
summary_query должен быть длинным и подробным описанием документа на 3 предложения минимум.
Поиск конкретного набора документов делай в 3 попытки.
Пример последовательности попыток поиска неизвестных документов:
    1. поиск по ключевым словам в названии; 
    2. поиск по абстрактному описанию длиной в 2-4 предложения; 
    3. поиск по всем файлам.
Пример сбора информации о наборе документов
    1. получить компактный список всех документов по id;
    2. уточнить список по фильтрам;
    3. Получить полную информацию о каждом документе по отдельным `name_query`.

Если инструмент выводит не все документы, обязательно (он об этом сообщает в конце), обязательно проводи дополнительные поиски потенциально нужных документов с фильтрами.

Чтобы получить полную информацию по конкретному документу (включая полное содержимое сводки), передай `file_id`.

**Зависимости:** Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.
