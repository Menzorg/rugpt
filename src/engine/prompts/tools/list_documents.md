# list_documents

Показать документы, доступные вызывающему в его организации. Без фильтров: если документов ≤ 100 — полный формат с размером и кратким содержанием; если > 100 — компактный список (id, имя файла, `is_table`), усечённый до 500. Чтобы найти нужный документ в большом каталоге — используй `name_query` или `summary_query` (оба идут через векторный поиск). 
## Правила использования
summary_query должен быть длинным и подробным описанием документа на 3 предложения минимум.
Поиск конкретного набора документов делай в 3 попытки.
Пример последовательности попыток: 
    1. поиск по ключевым словам в названии; 
    2. поиск по абстрактному описанию длиной в 2-4 предложения; 
    3. поиск по всем файлам.

Если инструмент выводит не все документы, обязательно (он об этом сообщает в конце), обязательно проводи дополнительные поиски потенциально нужных документов с фильтрами.

**Зависимости:** Результат (`file_id`) необходим для `rag_search` и `table_rows_search`.
