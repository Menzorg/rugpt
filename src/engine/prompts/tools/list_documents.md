### Назначение
Найти видимые документы организации. Использовать, если нужно искать по всей базе знаний, а не только по своим файлам.

### Особенности использования
- `name_query` — поиск по ключевым словам в имени файла и его кратком содержании.
- `summary_query` — поиск по абстрактному описанию краткого содержания файла.
- `user_id` — необязательный UUID владельца документов, если нужно сузить поиск до одного пользователя.
- `page` — номер страницы (по умолчанию 1, по 30 документов, сортировка по дате создания).
- `file_id` — точный id документа для просмотра его полного summary без ограничений на бюджет токенов.
- Без текстовых фильтров возвращает постраничный список всех видимых документов.
- Нельзя отвечать на вопросы по содержимому документов без последующего применения `rag_search`.
- Документы без статуса "indexed" недоступны для поиска по содержимому.

### Ограничения
Не более 8 вызовов за сессию.

### Зависимости
Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.
