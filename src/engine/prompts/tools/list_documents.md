# list_documents
Инструмент предназначен только для поиска документов по базе и получения информации о структуре документа. Получать ответы на вопросы пользователя по содержимому документов исключительно этим инструментом без последующего применения инструмента `rag_search` запрещено

`name_query` - поиск по ключевым словам
`summary_query` - поиск по абстрактному описанию

## Правила использования
Полное описание конкретного документа для исследования даст его поиск по `file_id`. Это дешевле первичного изучения структуры при помощи `rag_search`.
Нельзя получить никакой информации по документам, которые не имеют статус "indexed".

**Зависимости:** Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.

**Ограничения:** Не более 5 вызовов за раз
