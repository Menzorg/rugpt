# list_documents

Показать документы, доступные вызывающему в его организации. Без фильтров: если документов ≤ 30 — полный формат с размером и кратким содержанием; если > 30 — компактный список (id, имя файла, `is_table`), усечённый до 100. Чтобы найти нужный документ в большом каталоге — используй `name_query` или `summary_query` (оба идут через векторный поиск). 
На поиск конкретного повторяй попытки пока не найдёшь. Оптимальное количество попыток: 3. 
Пример последовательности попыток: 
    1. поиск по ключевым словам в названии; 
    2. поиск по абстрактному описанию длиной в 2-4 предложения; 
    3. поиск по всем файлам.

**Зависимости:** Результат (`file_id`) необходим для `rag_search` и `table_rows_search`.
