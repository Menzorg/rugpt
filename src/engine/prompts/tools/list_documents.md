# list_documents

Показать документы, доступные вызывающему в его организации. Без фильтров: если документов ≤ 75 — полный формат с размером и кратким содержанием; если > 100 — компактный список (id, имя файла, `is_table`), усечённый до 500. Чтобы найти нужный документ в большом каталоге — используй `name_query` или `summary_query`.
Инструмент не ищет изображения в базе документов.

`name_query` - поиск по ключевым словам
`summary_query` - поиск по абстрактному описанию

## Правила использования
Поиск конкретного набора документов делай в 3 попытки.
Пример последовательности попыток поиска неизвестных документов:
    1. поиск по ключевым словам в названии; 
    2. поиск по абстрактному описанию длиной в 2-4 предложения; 
    3. поиск по всем файлам.
Пример сбора информации о наборе документов без тематики
    1. получить компактный список всех документов по id;
    2. уточнить список по фильтрам;
    3. Получить полную информацию о каждом документе по отдельным `file_id`.
Пример сбора информации о наборе документов по конкретной тематике
    1. задать абстрактный `summary_query`
    2. задать `name_query` по ключевым словам

Если инструмент выводит не все документы - он об этом сообщает в конце

## Ограничения
Чтобы получить полную информацию по конкретному документу (включая полное содержимое сводки), передай `file_id`.
Ты не можешь получить никакой информации по документам, которые не имеют статус "indexed".

**Зависимости:** Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.
