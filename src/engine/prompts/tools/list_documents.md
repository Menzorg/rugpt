### Назначение
Найти документы, находящиеся в системе по запросу.

### Особенности использования
- `name_query` затрагивает названия документов и комментарии к ним, которые пользователь мог оставить при загрузке файла;
- `summary_query` затрагивает смысловую схожесть с категорией и оценке содержания документа по его началу;
- результат может содержать `comment` и `category` для отдельных документов;
- `comment` — прямое описание документа, которое пользователь указал при загрузке в систему;
- `category` — системное разделение документов на категории, настроенное администратором для всей организации;
- категория и комментарий есть не у каждого документа, но если она указана, считай ее очень сильным сигналом при выборе подходящих документов: смысл категории и комментария важнее смысла `summary`;
- документы без статуса "indexed" недоступны для поиска по содержимому.

### Зависимости
Результат (`file_id`) необходим для `rag_search`, `expand_chunk` и `table_rows_search`.
