# expand_chunk

Получить фрагмент нетабличного документа по `chunk_index` вместе с соседними фрагментами: один до него и один после него. Используй, когда уже известен нужный `chunk_index` и нужен локальный контекст вокруг найденного куска текста.
Использовать в случаях:
1. когда по фрагменту нужно восстановить список или полную инструкцию
2. когда фрагмент вырван из важного контекста

**Зависимости:** `file_id` — UUID документа, можно получить через `list_documents`; `chunk_index` — индекс фрагмента, можно получить из результатов `rag_search`.
