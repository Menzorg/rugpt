### Назначение
Проанализировать изображение, загруженное пользователем, по `file_id`.

### Особенности использования
- `file_id` — UUID файла-изображения.
- `query` — вопрос или инструкция к изображению.

### Ограничения
Работает только с изображениями (`jpg`, `jpeg`, `png`, `gif`, `webp`). Если файл не является изображением, инструмент вернёт ошибку.

### Зависимости
`file_id` — получи через `list_own_documents` или `list_global_documents`.
