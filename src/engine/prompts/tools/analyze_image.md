# analyze_image

Проанализировать изображение, загруженное пользователем, по `file_id`.

**Аргументы:**
- `file_id` — UUID файла-изображения.
- `query` — вопрос или инструкция к изображению.

Инструмент работает только с изображениями (`jpg`, `jpeg`, `png`, `gif`, `webp`). Если файл не является изображением, инструмент вернёт ошибку.
