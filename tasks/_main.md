> синхронизировать этот индекс вручную.

> Условные обозначения:
> - ✅ done — все подзадачи закрыты;
> - 🚧 in progress — работа идёт, часть подзадач закрыта;
> - ⏳ blocked / waiting — ждём внешнюю зависимость или подтверждения;
> - 📌 deferred — отложено по приоритету;
> - 📖 reference — справочный материал, не «выполняется».

## Правила синхронизации

- При смене статуса подзадачи в файле-таске — пересчитать `Сделано / Всего`
  здесь и перерисовать прогресс-бар (10 ячеек, 1 ячейка ≈ 10%).
- При появлении нового файла-таска в `tasks/` или `tasks/backlog/` — добавить
  строку в соответствующую секцию.
- Имя файла-таска — `snake_case.md`, кратко и по сути (`kafka_retry_policy.md`,
  а не `task1.md`).
- Перемещение между активными и backlog — просто `mv tasks/<name>.md tasks/backlog/`
  (или обратно) + правка ссылки в этом индексе.

## Шаблон файла-таска

Каждый файл-таск содержит:

1. **Заголовок** + цель + подход + явный список «что НЕ входит».
2. **Краткий обзор задач** — таблица подзадач со статусом каждой.
3. **Структура файлов** — какие файлы трогаем и зачем.
4. **Архитектурные решения** — ключевые выборы и их обоснование.
5. **Подзадачи** — по секции на каждую, с чекбоксами `- [ ]` для шагов.
6. **Self-review** — покрытие исходного запроса, риски.
7. **Рекомендуемый порядок** — что сделано, что дальше.
